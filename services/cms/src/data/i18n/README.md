# GUI / interface languages

Planned UNESCO portal interface (GUI) languages.

These are **not** taxonomy terms and are **not** imported via `term_trans_ex_im`.
Drupal configurable languages live in config (`language.entity.*`).

Currently enabled in the CMS: English (`en`), French (`fr`, partial).
The other four are aspirational for future UI localization.

See [`gui-languages.csv`](gui-languages.csv) for the list.

Content/document language for resources and news uses taxonomy vocabulary
`languages`, seeded from [`../taxonomies/languages-iso.csv`](../taxonomies/languages-iso.csv)
(includes ISO codes for EventRegistry and other source mapping).
